# REPOSITORY RULE: HYBRID EVENT CODING & WORKFLOW PROTOCOL

## Dynamic Event Coding Division:
1. **Simple Frontend Events (Sự Kiện Đơn Giản & Dễ)**:
   - Provide ultra-clear line-by-line instructions, code snippets, and explanations.
   - Guide the user to type/write the event handler logic by hand.

2. **Complex Events & Heavy Infrastructure Setup (Sự Kiện & Cấu Trúc Tương Đối Phức Tạp)**:
   - Perform the code implementation automatically.
   - Build, verify, and deliver clean results directly without forcing the user to handle intricate boilerplate or multi-file event orchestration.
